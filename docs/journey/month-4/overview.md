# Month 4: Production Hardening, Cloud Deployment & Academic Thesis

**Milestone Target:** Elevate NIRMAYA from a development monorepo to an enterprise production platform through distributed WebSockets, Zero-Trust clinical RBAC hardening, Docker Swarm / Kubernetes containerization, automated CI/CD pipelines, and the academic thesis monograph (**Production Master Release `v1.0.0`**).

---

## 1. Month 4 Architectural Scope

Month 4 delivers production resilience, high availability, and exhaustive academic verification:
- **Week 13: Distributed WebSockets & Real-time Queue Telemetry (Days 61–65):** Redis Pub/Sub WebSocket scaling, live patient queue status, clinical notification toasts, and distributed audit logging.
- **Week 14: Clinical Security Hardening & Zero-Trust Verification (Days 66–70):** OWASP ASVS compliance, SQL injection / XSS fuzzing, HIPAA/DISHA data privacy controls, and penetration testing.
- **Week 15: Production Containerization & Cloud Deployment (Days 71–75):** Multi-stage production Dockerfiles, docker-compose orchestration, automated GitHub Actions CI/CD, SSL/TLS reverse proxy (Caddy/Nginx), and PostgreSQL high-availability configuration.
- **Week 16: Academic Project Monograph & Final Release v1.0.0 (Days 76–80):** 80-day retrospective, academic project thesis documentation, live demonstration recording, and Production Master Release `v1.0.0`.
